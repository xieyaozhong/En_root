# EnRoot

TOEIC＋TOEFL 字根／字首記憶練習 App，每回固定 10 題，並延伸到 GRE／SAT／GMAT／IELTS 高階學術詞彙。

## 目前功能

- TOEIC 11,154 詞核心庫＋TOEFL／GRE／SAT／GMAT／IELTS 高階補充庫（執行時載入並去重）
- 每回 10 題
- 綜合模式：字義、字根、情境填空
- 字根強化模式
- 生難字模式：答錯自動加入，可手動收藏
- 字首／字根／字尾拆解
- 同根字自動連結
- 生難字記憶法
- 考試詞庫切換：TOEIC 990+／TOEFL 120+／高階學術／雙滿分超額
- TOEIC 分數區間篩選
- 本機答題統計與熟悉度
- 手機／平板／桌機響應式介面
- 完整詞庫無法連線時，自動使用內建示範詞庫

## 詞庫

App 會在瀏覽器端載入並合併：
- `kknono668/toeic-vocab-tw`（TOEIC）
- `grhliu/wordtyper-vocabularies`（TOEFL／GRE／SAT／GMAT／IELTS）

公開資料集含 11,154 個 English–Traditional Chinese TOEIC 情境詞條，本 App 會先依 star rating（TOEIC 重要度）排序，再取核心 10,000 筆作為主要練習池，抽題時也會再次依重要度加權。

資料集頁面：https://huggingface.co/datasets/kknono668/toeic-vocab-tw

## 執行

這是純靜態網頁，不需要 npm、不需要後端。

直接開啟 `index.html`，或用 GitHub Pages 部署即可。

## 學習設計

單字不是只顯示中文，而是嘗試建立：

`prefix + root + suffix → 核心概念 → 中文意思 → 同根字`

例如：

`trans + port → across + carry → transport → 運輸`

對不適合硬拆字根的單字，改用情境、語意或專屬記憶法，避免錯誤字源拆解。

## 儲存

生難字、答題統計與熟悉度存放在瀏覽器 `localStorage`，不會上傳使用者學習資料。


## 超額覆蓋策略

TOEIC 與 TOEFL 並沒有一份官方固定的「滿分單字表」。EnRoot 因此採用超額覆蓋：先保留 TOEIC 商務核心，再加入 TOEFL 學術核心，最後以 GRE、SAT、GMAT、IELTS 詞庫作為滿分以上的高階延伸。

目前補充來源的原始規模：TOEFL 6,959、GRE 7,485、SAT 4,471、GMAT 2,996、IELTS Core 4,974、IELTS Advanced 3,117；這些補充詞庫彼此去重後約 13,213 個不同詞，再與 TOEIC 詞庫合併去重。

## 字根地圖

新增 `roots.html` 可搜尋字根頁，整合 `generated-english-roots-list` 的 1,061 組英文字根、字首與字尾；主練習頁也會載入同一套資料，並保留內建中文核心字根作為優先解釋。


## Word Relic 像素單字抽卡

- 每完成 10 題獲得 1 次抽卡
- 依當回合答題表現提高高稀有度機率
- N / R / SR / SSR / UR 五級卡片
- 161 張單字卡，涵蓋 TOEIC、TOEFL、學術字彙與經典詞源故事
- 每張卡包含繁體中文、構詞線索、來源語言、年代與詞源故事
- 新版卡面依單字語意生成專屬像素場景，例如 reimbursement＝退回金幣、itinerary＝地圖路線、gravity＝向下墜落、oxygen＝O₂ 氣泡
- 重複卡會累計收藏張數
- `cards.html` 提供可搜尋的卡片圖鑑
- 收藏紀錄儲存在瀏覽器 localStorage

> 卡片中的「故事」指詞源與語義演變故事，不代表每個單字都有單一明確的「發明者」。有爭議的民間詞源會以較保守的方式描述。

## 符文地牢：動作打字冒險

從首頁、卡片圖鑑或字根地圖開啟 `dungeon.html`，選擇一張已收藏的單字卡作為入場符文。每場正式冒險消耗一張卡片；在俯視角像素競技場中自由移動、衝刺躲避攻擊，再輸入英文咒語施法。沿途選擇路線、取得道具與掉落物，挑戰各層守關 Boss。試玩模式可直接體驗戰鬥，不消耗收藏卡片。

- 正式冒險保留目前進度，重新整理後可以接續同一場冒險，不會再次扣卡。
- 同一時間保留一場正式冒險；結束或放棄後才可使用新卡入場，已使用的入場卡不退還。
- 卡片數量扣到零時仍保留首次取得時間、最後取得時間與稀有度紀錄。
- 勝敗與最遠關卡獨立保存；試玩不累計正式戰績，也不增加原有卡片收藏。
- 卡片收藏使用原有的 `enroot_cards`；冒險使用 `enroot_dungeon_v1`。兩者必須在相同瀏覽器、相同網站來源開啟，才能共用收藏資料。

`dungeon-storage.js` 提供收藏驗證、單張入場扣除、續玩、結算與放棄 API。入場會先寫入 `enroot_dungeon_entry_pending` 紀錄，再扣除卡片並儲存冒險；如入場中斷，會依實際已儲存的收藏狀態接續或取消未扣卡的入場，恢復程序不會回寫舊收藏。損壞的儲存資料會保留並顯示錯誤，不會以空白存檔覆蓋。支援 Web Locks 的瀏覽器會序列化不同分頁的地牢寫入；其他瀏覽器則在單一頁面中依序處理操作。

### 操作

- `WASD` 或方向鍵移動，`Space` 沿移動方向衝刺；衝刺提供短暂无敵並有冷卻時間。
- 探索時必須走近傳送門、戰利品祭壇、營火或 NPC，按 `E`／`Enter` 互動；手機使用「E · 互動」。交談中 `Esc` 返回走位，離開商店或 NPC 房間須走到出口。
- 戰鬥時 `Enter` 進入詠唱，輸入顯示的英文後再按 `Enter` 施法。咒語鎖定射程內最近的敵人，距離不足時須先靠近。
- 詠唱時停止移動並消耗專注，使敵人、飛彈與陷阱減速；專注耗盡後危險恢復正常速度。離開詠唱後自動恢復專注。
- 詠唱中按 `Esc` 返回走位，走位時按 `Esc` 暫停。切換分頁或視窗失去焦點時自動暫停。
- 手機提供方向按鈕、衝刺與詠唱按鈕；另有全螢幕、音量與減少動畫設定。

### 地牢內容

- 三個區域、12 個探索節點：苔光秘林／棘冠典獄長、碎月書庫／鏡月女巫、失名王座／失名之王。三位 Boss 皆有第二階段，攻擊會先顯示地面預警，能以實際走位避開。
- 棘冠典獄長使用追蹤落點與環形震波；鏡月女巫施放放射彈幕與交叉封線；失名之王結合星環、突刺與大範圍湮滅。
- 六種戰鬥房間：古柱迴廊的石柱掩體、碎光十字的交錯陷阱、餘燼環庭的熔池、回聲競技場的三波援軍、雙橋密道的狹窄通道，以及月露泉庭的回復泉。
- 敵群包含追擊者、遠程射手與蓄力衝撞者；石柱和牆壁會阻擋移動與敵方飛彈。
- 隨機戰鬥、精英、寶箱、營火、商店與 NPC 相逢；金幣與道具有機會直接掉落，戰利品三選一。
- 商人、療癒師、鍛造師、製圖師、擺渡人都有獨立像素形象。四位旅途 NPC 提供一次性幫助，或輸入指定挑戰文字展開雙階段 Boss 戰；接受幫助後本次不能再挑戰。商人可先交易再挑戰，挑戰文字為 `debt`。
- 五位 NPC Boss 各有不同攻勢與一件必掉的專屬遺物，特殊遺物不會出現在一般掉落或商店。擊敗 NPC 不算突破主線封印，也不會跳過主線 Boss。
- 5 種消耗道具、12 種普通與 5 種 NPC 專屬遺物，效果只存在於本次冒險。新增迅風羽、雷步印、連星線、霜時石，分別強化移動、衝刺範圍傷害、連鎖施法與敵群減速。
- 每五次成功施法輪到入場卡片的專屬咒語。大小寫不拘，拼錯會受到少量傷害，但不換題。
- 入場前可選故事／標準／試煉難度，調整敵人傷害與飛彈速度；舊存檔使用標準難度，接續戰鬥時會自動建立競技場。
- 三套原創 32 小節區域配樂：`Fireflies Beneath the Thorns`（秘林）、`Lanterns in the Lost Library`（書庫）、`The Obsidian Crown`（王座）。戰鬥與 Boss 會增加配器及節奏，詠唱時降低配樂音量；另有施法、衝刺、受傷、治療及戰利品音效。
- 配樂預設關閉，按「配樂」按鈕啟用。全部聲音由 Web Audio 合成，不下載錄音素材；暫停、靜音或隱藏分頁會停止排程並釋放音符。

### 驗證

使用 Node.js 直接執行，不需要安裝套件：

```sh
node tests/dungeon-engine.test.cjs
node tests/dungeon-storage.test.cjs
node tests/dungeon-arena.test.cjs
node tests/dungeon-audio.test.cjs
node tests/dungeon-ui.test.cjs
node tests/dungeon-arena-renderer.test.cjs
node tests/dungeon-explore.test.cjs
node tests/dungeon-npc.test.cjs
```

引擎與儲存測試涵蓋三位 Boss 與完整通關、80 組隨機路線、道具效果，以及扣卡、重複操作、儲存失敗復原、不同分頁的衝突與結算去重。競技場另測移動、碰撞、衝刺、專注、空間攻擊與房間機制；音訊使用可推進時鐘的 Web Audio 模擬測試三區完整曲目循環、詠唱音量、暫停／靜音、分頁隱藏、延遲啟用競態及資源釋放。

操作整合測試以模擬 DOM 執行真實引擎與操作事件，涵蓋鍵盤、觸控、詠唱、暫停及續玩。繪圖測試驗證回復泉範圍、角色與攻擊幾何及 Canvas 狀態平衡；實際像素外觀與響應式排版仍需在瀏覽器確認。

探索及 NPC 測試另覆蓋互動距離、對話與交易權限、特殊挑戰、專屬掉落、兩階段攻擊、幫助去重、出口進度與 JSON 存檔接續。
