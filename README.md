# EnRoot

TOEIC＋TOEFL 字根／字首記憶練習 App，每回固定 10 題，並延伸到 GRE／SAT／GMAT／IELTS 高階學術詞彙。

## 目前功能

- TOEIC 11,154 詞核心庫＋TOEFL／GRE／SAT／GMAT／IELTS 高階補充庫（執行時載入並去重）
- 每回 10 題
- 綜合模式：字義、字根、情境填空
- 字根強化模式
- 生難字模式：答錯自動加入，可手動收藏
- 字首／字根／字尾拆解
- 同根字自動連結
- 生難字記憶法
- 考試詞庫切換：TOEIC 990+／TOEFL 120+／高階學術／雙滿分超額
- TOEIC 分數區間篩選
- 本機答題統計與熟悉度
- 手機／平板／桌機響應式介面
- 完整詞庫無法連線時，自動使用內建示範詞庫

## 詞庫

App 會在瀏覽器端載入並合併：
- `kknono668/toeic-vocab-tw`（TOEIC）
- `grhliu/wordtyper-vocabularies`（TOEFL／GRE／SAT／GMAT／IELTS）

公開資料集含 11,154 個 English–Traditional Chinese TOEIC 情境詞條，本 App 會先依 star rating（TOEIC 重要度）排序，再取核心 10,000 筆作為主要練習池，抽題時也會再次依重要度加權。

## 執行

這是純靜態網頁，不需要 npm、不需要後端。

直接開啟 `index.html`，或用 GitHub Pages 部署即可。

## 學習設計

單字不是只顯示中文，而是嘗試建立：

`prefix + root + suffix → 核心概念 → 中文意思 → 同根字`

例如：

`trans + port → across + carry → transport → 運輸`

對不適合硬拆字根的單字，改用情境、語意或專屬記憶法，避免錯誤字源拆解。

## 儲存

生難字、答題統計與熟悉度存放在瀏覽器 `localStorage`，不會上傳使用者學習資料。


## 超額覆蓋策略

TOEIC 與 TOEFL 並沒有一份官方固定的「滿分單字表」。EnRoot 因此採用超額覆蓋：先保留 TOEIC 商務核心，再加入 TOEFL 學術核心，最後以 GRE、SAT、GMAT、IELTS 詞庫作為滿分以上的高階延伸。

目前補充來源的原始規模：TOEFL 6,959、GRE 7,485、SAT 4,471、GMAT 2,996、IELTS Core 4,974、IELTS Advanced 3,117；這些補充詞庫彼此去重後約 13,213 個不同詞，再與 TOEIC 詞庫合併去重。

## 字根地圖

新增 `roots.html` 可搜尋字根頁，整合 `generated-english-roots-list` 的 1,061 組英文字根、字首與字尾；主練習頁也會載入同一套資料，並保留內建中文核心字根作為優先解釋。


## Word Relic 像素單字抽卡

- 每完成 10 題獲得 1 次抽卡
- 依當回合答題表現提高高稀有度機率
- N / R / SR / SSR / UR 五級卡片
- 161 張單字卡，涵蓋 TOEIC、TOEFL、學術字彙與經典詞源故事
- 每張卡包含繁體中文、構詞線索、來源語言、年代與詞源故事
- 新版卡面依單字語意生成專屬像素場景，例如 reimbursement＝退回金幣、itinerary＝地圖路線、gravity＝向下墜落、oxygen＝O₂ 氣泡
- 重複卡會累計收藏張數
- `cards.html` 提供可搜尋的卡片圖鑑
- 收藏紀錄儲存在瀏覽器 localStorage

> 卡片中的「故事」指詞源與語義演變故事，不代表每個單字都有單一明確的「發明者」。有爭議的民間詞源會以較保守的方式描述。

## 符文地牢：動作打字冒險

從首頁、卡片圖鑑或字根地圖開啟 `dungeon.html`，選擇一張已收藏的單字卡作為入場符文。每場正式冒險消耗一張卡片；在俯視角像素競技場中自由移動、衝刺躲避攻擊，再輸入英文咒語施法。沿途選擇路線、取得道具與掉落物，挑戰各層守關 Boss。試玩模式可直接體驗戰鬥，不消耗收藏卡片。

- 正式冒險保留目前進度，重新整理後可以接續同一場冒險，不會再次扣卡。
- 同一時間保留一場正式冒險；結束或放棄後才可使用新卡入場，已使用的入場卡不退還。
- 卡片數量扣到零時仍保留首次取得時間、最後取得時間與稀有度紀錄。
- 勝敗與最遠關卡獨立保存；試玩不累計正式戰績，也不增加原有卡片收藏。
- 卡片收藏使用原有的 `enroot_cards`；冒險使用 `enroot_dungeon_v1`。兩者必須在相同瀏覽器、相同網站來源開啟，才能共用收藏資料。

`dungeon-storage.js` 提供收藏驗證、單張入場扣除、續玩、結算與放棄 API。入場會先寫入 `enroot_dungeon_entry_pending` 紀錄，再扣除卡片並儲存冒險；如入場中斷，會依實際已儲存的收藏狀態接續或取消未扣卡的入場，恢復程序不會回寫舊收藏。損壞的儲存資料會保留並顯示錯誤，不會以空白存檔覆蓋。支援 Web Locks 的瀏覽器會序列化不同分頁的地牢寫入；其他瀏覽器則在單一頁面中依序處理操作。

### 操作

- `WASD` 或方向鍵移動，`Space` 沿移動方向衝刺；衝刺提供短暂无敵並有冷卻時間。
- 衝刺接受冷卻結束前 140ms 的提前輸入，並在衝刺結束後立即接續搖桿走位；技能鍵用圓環與秒數顯示冷卻。暫停、交談、離頁與切換房間會清除尚未執行的輸入。
- 探索時必須走近傳送門、戰利品祭壇、營火或 NPC，按 `E`／`Enter` 互動；手機使用右側「互動」。交談中 `Esc` 返回走位，離開商店或 NPC 房間須走到出口。
- 戰鬥時 `Enter` 進入詠唱，輸入顯示的英文後再按 `Enter` 施法。咒語鎖定射程內最近的敵人，距離不足時須先靠近。
- 按下詠唱後顯示 QTE 字母鍵帽：亮起下一鍵、正確變綠、錯誤標紅、顯示輸入進度與剩餘專注時間。桌機完整輸入後按 Enter／施法。手機依提示點最多 4 組符文，拼完即自動施放，不開啟系統鍵盤；全螢幕時符文收在右手技能區上方，保留戰場中央視線。字母逐一變色，按錯只提示重選，專注仍持續消耗。
- 遊戲控制區抑制長按選取、拖曳與系統選單，咒語及 NPC 輸入框保留文字編輯操作。
- 手機衝刺在第二指按下時立即觸發，保留左指搖桿方向；可一邊拖動搖桿、一邊點符文詠唱，完成施法後繼續走位。衝刺會退出詠唱並保留輸入草稿，射程外／敵人尚未進場時保留完整咒語，靠近後手動重試。旋轉螢幕、暫停與離開頁面會清除手勢。
- 火焰彗星、冰晶霜裂、分岔雷電、旋流風刃、治癒花瓣、六角護盾、奧義星印與符文飛彈各有不同輪廓和動畫；新增 `wind` 風刃咒。減少動畫時使用固定幾何淡出，限制特效範圍以保留地面預警。
- 詠唱會消耗專注，使敵人、飛彈與陷阱減速；手機可以用 75% 步速邊走邊詠唱，移動時一般戰鬥至少保持 55% 時間速度，近戰首領保持 72%，仍需看準攻擊時機。桌機詠唱維持站定輸入。專注耗盡後危險恢復正常速度，離開詠唱後自動恢復專注。
- 詠唱中按 `Esc` 返回走位，走位時按 `Esc` 暫停。切換分頁或視窗失去焦點時自動暫停。
- 手機提供隨按下位置定位的 360 度浮動搖桿，輕推慢走、推遠加速、放開停止；左手移動，右手使用詠唱、衝刺、藥水與互動。開始／接續冒險時嘗試進入全螢幕；支援的瀏覽器啟用原生全螢幕與橫向鎖定，其餘使用滿版配置並提示橫放。戰場鋪滿可用畫面，控制鍵疊在兩側，保留場景完整比例；生命列、首領資訊及功能鍵分置上方。主動離開全螢幕後不自動重開，可由「橫向全螢幕」再次進入。手札、暫停、配樂、補血與 NPC 對話仍可操作。

- 每五次成功施法輪到入場卡片的專屬咒語。大小寫不拘，拼錯會受到少量傷害，但不換題。
- 入場前可選故事／標準／試煉難度，調整敵人傷害與飛彈速度；舊存檔使用標準難度，接續戰鬥時會自動建立競技場。

- 配樂預設關閉，按「配樂」按鈕啟用。全部聲音由 Web Audio 合成，不下載錄音素材；暫停、靜音或隱藏分頁會停止排程並釋放音符。

### 星露紀事擴充

- 四章主線講述替失名世界找回記憶；劇情列位於戰場與觸控操作台之後，閱讀手札時暫停冒險。
- 星露法師露米娜是 24 歲的星象研究員。新遠征第一區第三節點提供相逢路線，其他節點也可能遇見；必須走近交談才能談心、贈禮或邀請同行。
- 戰鬥／寶箱可能獲得月露小花（好感 +3）、蜜星花茶（+4）、星砂玻璃瓶（+6）。同一個節點的掉落只判定一次；每次相逢最多送三件禮物，談心最多增加一次好感。
- 好感 20 成為熟悉的旅伴、45 解鎖「星光之約」。支線包含追尋殘星、未說完的話及失約星影首領三幕，完成後返回原本 NPC 節點，從出口繼續主線。重新整理可接續支線，挑選戰利品不會跳過主線節點。
- 完成星約且好感達到 75 後，可由玩家主動選擇告白，解鎖戀愛回憶與戀人結局；也可維持旅伴關係。星露手札可回看已收藏劇情。
- 正式遠征的禮物、好感、戀愛與回憶，和進度一起原子儲存在 `enroot_dungeon_v1.relationship`。戰敗或結束冒險不清除關係。練習模式使用手札副本體驗，離開後不累計；不修改原有收藏卡片。
- 原創玫瑰銀短髮立繪與像素人物；四區加入遠景、材質、窗光與植栽，星庭有星龍、星影和三種新敵人。玩家／同伴標記保留，地面攻擊範圍以實際機制繪製。
- 配樂新增星庭、星龍、失約星影、露米娜試煉與相逢／戀愛／支線主題；柔和音頭、自然衰減、回音與場景淡出維持靜音、暫停與降低動態效果控制。
- 生命列的快捷藥水可在移動或詠唱中使用，保留已輸入字母；滿血、沒有藥水、暫停或交談時不會消耗。

- 每次新遠征保存一份 24 節點旅圖：依區域抽取房間、三種地形配置、混合／獵群／交叉火力／突擊四種敵群，以及本層星象。相鄰節點的房間方案不同；同一局的配置會隨進度保存。
- 秘林首領：棘冠典獄長或孢冠菌后；書庫首領：鏡月女巫或千面鏡獸；王座首領：失名之王或空鐘司祭；星庭首領：忘誓星龍或彗尾女皇。每區遇見其中一位，合計八位主線首領，各有不同像素模型、兩階段攻勢及原創配樂。
- 孢冠菌后記錄玩家位置播下孢雨，隨後封鎖菌環；千面鏡獸以延遲鏡爪與折返連段追擊；空鐘司祭敲出三重鐘波、切開場地；彗尾女皇以兩側彗星及延遲星隕迫使玩家移動。攻擊先顯示預警。
- 星象包含平穩、敵人加速但多掉金幣、開場護盾、敵人生命提高但戰利金幣增加。僅套用一般／精英戰，NPC 試煉與露米娜支線維持原有機制。
- 路線入口、獎勵祭壇、營火、NPC 與出口的位置也隨旅圖變化。走近入口可看地形與星象情報；橫向全螢幕時可在手札查看，閱讀時暫停戰鬥。
- 章節故事與旅途路徑會對應當次首領。讀檔不重抽首領或地形；既有存檔沿用原本配置，開始新遠征即可體驗完整隨機內容。
- 新增四首首領配樂，首領曲目現共 18 首（8 主線、9 NPC、1 支線），另有 4 首區域及 3 首劇情曲。


### 細緻像素角色與連貫動作

- 依照使用者提供的 DungeonSlasher 影片所呈現的像素細節、清楚姿勢與衣髮跟隨方向，製作原創主角與露米娜的角色繪製模組 `dungeon-character.js`。保留遊戲的俯視走位與現有戰鬥規則。
- 角色以分層頭髮、臉部明暗、外套內襯、金屬配件、關節與法杖構成；腳步、手臂、身體與衣襬各自活動，包含背面與左右朝向。
- 動作包含站立呼吸、行走、轉身、衝刺、詠唱、施法及受擊。步態跟隨移動距離，動作之間漸變；動畫使用繪圖循環，不改動施法判定或碰撞範圍。
- 暫停保留當下姿勢；減少動態效果使用安靜的姿勢表現。動畫資料只在繪圖器中保存，不增加冒險存檔體積。
- 本次依使用者要求直接發布，未執行新增測試或瀏覽器驗證。

### 首領對決與三重破咒

- 敵人的蓄力、施放、揮擊與收招由戰鬥狀態驅動；角色姿勢和傷害判定共用出招節奏。主線首領、NPC 試煉及一般敵群使用各自的身體、肢體與武器動作。
- 法術型首領會準備需要打斷的強力咒語。依序輸入畫面提示的三組短咒語即可破咒；手機沿用符文按鈕。倒數不會因詠唱而停住，暫停遊戲才會暫停倒數。未完成會遭受重擊，完成則讓首領露出反擊空檔。
- 近戰首領包含失名之王、千面鏡獸、星鐵鍛師與紙甲衛士。觀察蓄勢與鎖定方向，抓準出手時機衝刺；連段之間仍可能追擊，完整收招才是較安全的反擊機會。精準閃避獲得額外反擊優勢。
- 戰鬥提示顯示出招階段、連段與破咒進度；新增蓄力、揮擊、閃避成功與破咒音效，沿用配樂開關、暫停與音量控制。手機版的提示保持緊湊，搖桿及衝刺按鈕仍可使用。
- 此次依使用者要求直接更新部署，未執行遊戲測試或瀏覽器驗證。

### 對決節奏銜接

- 近戰命中區域直接跟隨出招階段與連段編號；武器開始揮出後才有傷害，收招、換招及死亡會撤除該次攻擊判定。
- 精準閃避獎勵會保留至完整連段結束，再開啟至少 2.5 秒的雙倍反擊窗口。後續遭到生命傷害會失去尚未啟用的獎勵；護盾仍能保護這次機會。HUD 以橘色提示連段未完，綠色提示正式反擊時機。
- 失名之王使用延遲重斬與王劍橫掃；星鐵鍛師偏重慢速巨鎚與短距掃擊；千面鏡獸以鏡爪連續逼近；紙甲衛士使用長距窄角突刺與迴斬。各自的第二階段延伸連段也保留方向性退路。
- 角色動作連續銜接蓄勢停頓、出招及收勢，鎖定後朝向與地面判定一致。受擊反應疊加在正在執行的招式上，只有真正失衡才中止動作。
- 三重破咒期間暫存本場普通咒語的輸入，結束後回填但不自動施放；換咒語、換場或重新載入不沿用過期文字。手機仍使用原本的符文按鈕。
- 依使用者要求直接發布，未執行測試或瀏覽器驗證。
